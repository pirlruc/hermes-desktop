## [0.1.0] - 2026-11-21

Linux amd64 package for the local library sync core. The package is unsigned. The app reads a Zotero or Qiqqa library, asks before a PDF upload, and calls a Delphi Engine HTTP API. This tag vendors the current OpenAPI document.
