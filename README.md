# hermes-desktop

Tauri desktop app that syncs a local reference library with Delphi Engine.

The app reads a local Zotero or Qiqqa library, asks before any PDF upload, and talks to a pinned Delphi Engine release. It does not read the Delphi Engine checkout on disk.
